Política de Privacidade

Última atualização: Março de 2026

Resumo: O Remover Marca d'Água processa suas imagens localmente no navegador. Não enviamos suas imagens para nenhum servidor. Seguimos a LGPD.

1. Quem Somos

Remover Marca d'Água é uma extensão para Google Chrome que utiliza inteligência artificial para remover marcas d'água de imagens diretamente no seu navegador.

2. Dados que Coletamos

Dados que NÃO coletamos:

  • Suas imagens — todo o processamento é feito localmente no navegador
  • Dados de navegação ou histórico
  • Dados pessoais de identificação
  • Cookies de rastreamento

Dados que coletamos:

  • Estatísticas de uso anônimas: Número de imagens processadas (para controle de limite diário)
  • Status de assinatura: Verificação do plano (gratuito/premium)
  • Dados de pagamento: Processados exclusivamente pelo Stripe — não armazenamos dados de cartão

3. Processamento de Imagens

Importante: Todas as imagens são processadas localmente no seu navegador usando um modelo de IA (ONNX Runtime). Nenhuma imagem é enviada para servidores externos. O modelo de IA é baixado uma vez e executado inteiramente no seu dispositivo.

4. Permissões

A extensão solicita as seguintes permissões:

  • activeTab: Para capturar a imagem na aba ativa quando solicitado pelo menu de contexto
  • contextMenus: Para adicionar a opção "Remover marca d'água" ao menu do botão direito
  • storage: Para salvar configurações e contagem de uso localmente

5. Análise de Uso (Google Analytics 4)

A extensão envia dados de uso anônimos ao Google Analytics 4 para melhorar suas funcionalidades:

  • Instalação e atualizações da extensão
  • Uso das funcionalidades (quais ferramentas são utilizadas)

Não são coletados: dados pessoais, imagens, histórico de navegação, endereços IP ou qualquer informação que permita identificação. Todos os dados analíticos são totalmente anônimos.

6. Compartilhamento de Dados

NÃO vendemos seus dados. Compartilhamos informações apenas com:

  • Google Analytics: Estatísticas de uso anônimas (conforme descrito acima)
  • Stripe: Processamento de pagamentos (apenas para assinantes premium)
  • Autoridades: Quando exigido por lei

7. Segurança

  • Processamento 100% local — suas imagens nunca saem do seu computador
  • Criptografia HTTPS em todas as comunicações com o servidor de licenças
  • Sem armazenamento de dados sensíveis

8. Seus Direitos (LGPD)

Conforme a Lei Geral de Proteção de Dados, você tem direito a:

  • Acesso: Solicitar cópia dos seus dados
  • Exclusão: Solicitar remoção dos seus dados
  • Revogação: Retirar consentimento a qualquer momento

Para exercer seus direitos, entre em contato através da página de suporte no Chrome Web Store.

9. Menores de Idade

A extensão não é destinada a menores de 18 anos.

10. Alterações

Esta política pode ser atualizada. A data da última modificação está no topo desta página.

11. Contato

Para questões sobre privacidade, utilize a página de suporte da extensão no Chrome Web Store.
